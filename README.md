# GRE Vocabulary Flash Cards

A beautiful, modern flashcard app to master GRE vocabulary with Bangla meanings, synonyms, and example sentences.

## Features

- 📚 **Organized Categories**: Vocabulary words organized into categories and subcategories
- 🇧🇩 **Bangla Meanings**: Every word comes with a Bangla translation
- 🔄 **Synonyms**: Related words to expand your vocabulary
- 📝 **Example Sentences**: Contextual examples to understand usage
- ✅/❌ **Know/Don't Know**: Track which words you know and need to review
- 🔀 **Shuffle**: Randomize cards for better learning
- 📱 **Responsive Design**: Works perfectly on desktop and mobile devices
- ✨ **Beautiful UI**: Modern design with smooth animations

## Technologies Used

- HTML5
- CSS3 (with modern gradients and animations)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter & Noto Sans Bengali)

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser, or
3. Run a local server:
   ```bash
   python -m http.server 8000
   # Then open http://localhost:8000
   ```

## Deployment to Vercel

1. Push your code to GitHub
2. Connect your repository to Vercel
3. Deploy! Vercel will automatically detect it as a static site

## How to Use

1. Select a category
2. Choose a subcategory
3. View the word on the flashcard front
4. Click or use the flip button to see details
5. Mark words as "Know" or "Don't Know" to organize your learning
6. Use the shuffle button to randomize cards

## Customization

You can add more vocabulary words by editing the `vocabularyData` array in `app.js`.
